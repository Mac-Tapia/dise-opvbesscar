# CityLearn v2 optional environment notes
# ======================================
#
# Do not install this file into the base Python 3.11 environment.
# CityLearn 2.x currently declares dependencies that pull OpenStudio and
# conflict with the SB3/Gymnasium stack used by the main training scripts.
#
# Base project install:
#   pip install -r requirements.txt
#
# Optional CityLearn-only experiment environment, without installing OpenStudio:
#   pip install citylearn==2.5.0 --no-deps
#
# Keep CityLearn optional until a compatible release is available for:
# - Python 3.11
# - stable-baselines3 2.7.x
# - gymnasium 0.29.x
# - no OpenStudio dependency in the base environment
